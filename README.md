## Linked List
Repository aşağıdaki 4 ana modülden oluşmaktadır:

* 🔹 **`01-singly-linear/`**: Tek Bağlı Doğrusal Liste (Singly Linear Linked List)
* 🔹 **`02-singly-circular/`**: Tek Bağlı Dairesel Liste (Singly Circular Linked List)
* 🔹 **`03-doubly-linear/`**: Çift Bağlı Doğrusal Liste (Doubly Linear Linked List)
* 🔹 **`04-doubly-circular/`**: Çift Bağlı Dairesel Liste (Doubly Circular Linked List)


* Her modülün içerisinde kullanıcı etkileşimli bir CLI menü dosyası (`menu.c`) yer alır.
